Welcome to VivaVials!

Master the Art of Color Sorting

🎯

Goal

Sort colored blocks into vials so each vial contains only one color (5 blocks per color).

🖱️

How to Play

Click a vial to select it, then click another vial to pour blocks between them.

📋

Rules

  • You can only pour blocks on top of the same color or into empty vials
  • You can only move the top blocks from a vial
  • Use special powers like Color Swap and Undo wisely!
